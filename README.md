# algal-bloom-forecast

Research project for forecasting cyanobacterial harmful algal bloom intensity in western Lake Erie 1, 3, 7, and 14 days ahead.

## Tech stack

- Python
- pandas, NumPy, xarray, GeoPandas, Rasterio
- scikit-learn, XGBoost/LightGBM, PyTorch
- Matplotlib and Plotly
- pytest and Ruff

The project is currently in the data and experiment-planning stage.
