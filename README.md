# algal-bloom-forecast

Research project for forecasting cyanobacterial harmful algal bloom intensity in western Lake Erie 1, 3, 7, and 14 days ahead.

## Tech stack

| Area | Tools |
| --- | --- |
| Language | Python |
| Data and geospatial | pandas, NumPy, xarray, GeoPandas, Rasterio |
| Machine learning | scikit-learn, XGBoost/LightGBM, PyTorch |
| Visualization | Matplotlib, Plotly |
| Development | pytest, Ruff |
